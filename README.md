# BERLIN PALIMPSEST

> *"Every city is a text, rewritten over its past."*

**Berlin Palimpsest** is a brutalist electronic literature application that operates as a digital excavation device. Developed for the DAAD Artists-in-Berlin Program context, it utilizes generative AI and satellite imagery to reveal the suppressed frequencies and hidden narrative layers of Berlin.

This project rejects the static neutrality of cartography. Instead, it asserts that every coordinate holds a memory waiting to be reconstructed.

### The Core Concept: Palimpsest
A *palimpsest* is a manuscript page, either from a scroll or a book, from which the text has been scraped or washed off so that the page can be reused for another document. Berlin is treated here as a geographic palimpsest—where modern infrastructure covers historical trauma, exile, and resistance.

### Artistic Claims
1.  **AI as Medium, Not Creator:** This application uses Google Gemini not to "hallucinate" fiction, but as a spectral medium to summon documented archival facts and reconstruct visual memories of events that have been erased from the physical landscape.
2.  **Anti-Monumentalism:** We prioritize the glitch, the fragment, and the whisper over the statue. The interface design is intentionally brutalist, reflecting the harsh reality of historical excavation.
3.  **Non-Eurocentric Perspective:** The algorithm is tuned to seek out "Voices in Exile," "Invisible Labor," and "Queer Geographies," challenging the dominant tourist narratives of the city.

## 🛠 Technical Stack

*   **Engine:** React 19 + TypeScript
*   **AI Core:** Google Gemini 2.5 Flash (Text) & Gemini 2.5 Flash Image (Visual Reconstruction)
*   **Mapping:** Leaflet + Esri World Imagery (Satellite Layer)
*   **Styling:** Tailwind CSS (Brutalist Design System)
*   **Audio:** Procedural Web Audio API (No external assets)

---

## 🎮 How to Use

1.  **Initiate:** The application begins with a manifesto. Select a "Frequency" (Theme) to begin scanning the city.
2.  **Scan:** The system will triangulate coordinates based on historical data.
3.  **Excavate:** Once a target is locked, the narrative file opens.
4.  **Summon:** Use the **"SUMMON PAST"** feature to ask the AI to visually reconstruct the specific historical event described in the text, overlaying it onto the modern satellite map.
5.  **Minimize:** You can minimize the narrative evidence to focus purely on the visual reconstruction of the event.
